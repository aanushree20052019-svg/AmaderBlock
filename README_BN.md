# আমাদের ব্লক — Android Starter

এটি ছাতনা ব্লকের জন্য বাংলা-ভিত্তিক Android অ্যাপের **প্রাথমিক স্টার্টার প্রজেক্ট**।
এতে হোম স্ক্রিন, পরিষেবা বিভাগ, খবর/বিজ্ঞপ্তি, অভিযোগ ফর্মের নমুনা, অফলাইন নমুনা তথ্য এবং অ্যাডমিন স্ক্রিনের প্রাথমিক UI আছে।

## গুরুত্বপূর্ণ
- এটি এখনো সম্পূর্ণ উৎপাদন-প্রস্তুত অ্যাপ নয়।
- অভিযোগ/আবেদন জমা, বহু-অ্যাডমিন লগইন, ক্লাউড ডেটাবেস, পুশ নোটিফিকেশন ও Play Store প্রকাশের জন্য পরবর্তী ধাপে backend, নিরাপত্তা-নিয়ম, পরীক্ষা এবং নীতিমালা দরকার।
- সরকারি অনুমোদন না থাকলে অ্যাপটিকে সরকারি অ্যাপ বলে উপস্থাপন করবেন না। সরকারি প্রকল্পের তথ্য প্রকাশের আগে নির্ভরযোগ্য সরকারি উৎস থেকে যাচাই করুন।
- ব্যক্তিগত/সংবেদনশীল তথ্য সংগ্রহ করার আগে গোপনীয়তা নীতি, সম্মতি এবং নিরাপদ সংরক্ষণের ব্যবস্থা করুন।

## চালানোর জন্য
1. Android Studio-এর সাম্প্রতিক স্থিতিশীল সংস্করণ ইনস্টল করুন।
2. `File > Open` থেকে এই প্রজেক্টের ফোল্ডার খুলুন।
3. Gradle sync শেষ হতে দিন।
4. Android Emulator বা USB debugging চালু করা ফোন নির্বাচন করে Run চাপুন।

## পরবর্তী কাজ
1. Firebase Authentication দিয়ে অ্যাডমিন লগইন।
2. Firestore database ও role-based security rules।
3. অভিযোগের স্ট্যাটাস ট্র্যাকিং।
4. যাচাইকৃত ব্লক/পঞ্চায়েত যোগাযোগ ও সরকারি লিংক।
5. Offline cache, accessibility, privacy policy এবং Play Store প্রস্তুতি।
